# Komentář k zákonu č. 72/2000 Sb., o investičních pobídkách a o změně některých zákonů (zákon o investičních pobídkách)

Otevřený komentář k zákonu o investičních pobídkách — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; typy investičních akcí a formy pobídek, všeobecné podmínky, záměr a posudek, rozhodnutí o nabídce a o poskytnutí pobídky, maximální míra veřejné podpory, způsobilé náklady, kontrola a strategické investiční akce.

Konsolidované znění: dokument e-Sbírky `SB-2000-00072_2024-01-13`.
